Analytic check: half period = Rb * C * ln((Vcc + Vswing) / (Vcc - 0.7)) with Vswing = Vcc - Vf_LED - Vce_sat
(5 V: 47k * 10u * ln(7.3 / 4.3) = 0.249 s -> 0.50 s period; sim 0.545 s, within model tolerance).
The frequency is lower than the textbook 1.386 * Rb * C value because the LED drop reduces the collector swing.
