## 回退处理 cheat sheet

用户喊 "Phase X 回退" 时按以下处理：

1. Phase X 当前行 append 一行 🔄 redoing（**不删历史**）
2. Phase X+1, X+2, ... 所有 ✅ 改成 ⚠ stale
3. 关联 sentinel 文件由下次 skill 跑时覆盖
4. 已存在的 .kicad_sch / .kicad_pcb 让 user 决定 git restore 还是覆盖
5. 在 Change log 新加一行说明回退原因
